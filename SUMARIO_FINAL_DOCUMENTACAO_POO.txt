🎯 9 CONCEITOS POO ABORDADOS
═══════════════════════════════════════════════════════════════════════════════

✅ 1. ENCAPSULAMENTO
   └─ Esconde dados internos, expõe interface
   └─ Exemplo: shootCooldown privado, atirar() público

✅ 2. ABSTRAÇÃO
   └─ Simplifica complexidade de implementação
   └─ Exemplo: ObjetoJogo define contrato abstrato

✅ 3. HERANÇA
   └─ Reutiliza código de classe base
   └─ Exemplo: TanqueJogador e TanqueInimigo herdam de ObjetoJogo

✅ 4. POLIMORFISMO
   └─ Mesmo método, comportamentos diferentes
   └─ Exemplo: atualizar() implementado diferente em cada classe

✅ 5. USO DE THREADS
   └─ Execução paralela independente
   └─ Exemplo: 1 jogador + N inimigos + M tiros = múltiplas threads

✅ 6. INTERFACES
   └─ Define contrato que classes devem seguir
   └─ Exemplo: Atirador, Colidivel, Movimentavel

✅ 7. ENUMS
   └─ Constantes type-safe com valores relacionados
   └─ Exemplo: TipoTanque.AGIL, BALANCEADO, BLINDADO

✅ 8. COMPOSIÇÃO
   └─ Combina objetos para criar estruturas complexas
   └─ Exemplo: PainelJogoV2 contém Mapa, Jogador, Inimigos

✅ 9. TRATAMENTO DE EXCEÇÕES
   └─ Trata erros de forma robusta
   └─ Exemplo: try/catch em I/O e sincronização de threads

```
Método: GerenciadorColisao.tiroAcertaBase(Tiro, Mapa)
Verifica: Se tiro atinge bloco com tipo = 2 (BASE)
Funciona: Para tiros do jogador E inimigos
```

```
Quando: Qualquer tiro acerta a BASE
Ação: gameOver = true (imediato!)
Resultado: Finaliza jogo + exibe tela de Game Over
```

## 🎮 COMO FUNCIONA

### Fluxo Básico:

```
1. Mapa carrega com BASE no centro inferior
2. Tiro é disparado (jogador ou inimigo)
3. Tiro se move e verifica colisões
4. Se colide com BASE:
   └─ GerenciadorColisao.tiroAcertaBase() retorna true
   └─ gameOver = true
   └─ Tiro é removido
5. verificarEstadoJogo() vê gameOver = true
   └─ Finaliza tudo
   └─ Chama callback
   └─ Exibe tela de Game Over
```

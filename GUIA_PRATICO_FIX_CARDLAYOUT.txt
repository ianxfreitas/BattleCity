GUIA PRÁTICO: FIXAR CONFLITO DE FOCO COM CARDLAYOUT
====================================================

PASSO 1: IDENTIFICAR O PROBLEMA
================================

Sintomas:
✗ Dois painéis no CardLayout (PAUSE e GAMEOVER)
✗ Mesma classe interna usada para ambos
✗ Eventos de teclado recebidos por ambos simultaneamente
✗ Cursor resetado quando deveria estar em opção 2
✗ Ação errada é executada

Causa:
→ InputMap com WHEN_IN_FOCUSED_WINDOW

PASSO 2: MUDAR O INPUTMAP
==========================

ANTES (ERRADO):
   InputMap im = getInputMap(JComponent.WHEN_IN_FOCUSED_WINDOW);

DEPOIS (CORRETO):
   InputMap im = getInputMap(JComponent.WHEN_FOCUSED);

Por quê?
- WHEN_IN_FOCUSED_WINDOW: ambos painéis recebem eventos
- WHEN_FOCUSED: apenas painel com foco recebe eventos

PASSO 3: GARANTIR QUE O PAINEL SEJA FOCÁVEL
=============================================

No construtor do PainelMenuAcao:

   setFocusable(true);
   InputMap im = getInputMap(JComponent.WHEN_FOCUSED);
   // ... resto do código ...

PASSO 4: DAR FOCO AO PAINEL CORRETO
====================================

Após mostrar o painel no CardLayout:

   layout.show(container, "PAUSE");
   SwingUtilities.invokeLater(() -> {
       painelPausa.requestFocusInWindow(); // IMPORTANTE!
   });

Ou:

   layout.show(container, "GAMEOVER");
   SwingUtilities.invokeLater(() -> {
       painelGameOver.requestFocusInWindow(); // IMPORTANTE!
   });

Por quê SwingUtilities.invokeLater()?
→ Garante que o painel foi completamente renderizado antes de receber foco

PASSO 5: NÃO REMOVA O KEYLISTENER DEPOIS DE ADICIONAR INPUTMAP
================================================================

Se você tiver ambos (KeyListener E InputMap):
- O KeyListener pode conflitar com InputMap
- Remova o KeyListener se estiver usando InputMap

PASSO 6: TESTAR
================

1. Compile o projeto
2. Inicie um jogo
3. Pressione ESC para pausar
4. Navegue até opção 2 com CIMA/BAIXO
5. Pressione ENTER
6. RESULTADO ESPERADO: ✓ Opção 2 é executada

7. Reinicie o jogo
8. Deixe Game Over acontecer
9. Navegue até opção 2 com CIMA/BAIXO
10. Pressione ENTER
11. RESULTADO ESPERADO: ✓ Opção 2 é executada (volta ao menu)

SE AINDA NÃO FUNCIONAR:

Verificar lista:
☐ InputMap usa WHEN_FOCUSED?
☐ setFocusable(true) foi chamado?
☐ requestFocusInWindow() é chamado após layout.show()?
☐ KeyListener foi removido?
☐ Projeto foi recompilado?

RESUMO DA SOLUÇÃO:

┌─────────────────────────────────────────┐
│ WHEN_FOCUSED + requestFocusInWindow()   │
│ = Apenas um painel recebe eventos      │

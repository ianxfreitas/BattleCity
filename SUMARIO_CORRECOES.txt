SUMÁRIO DE CORREÇÕES - BOTÃO "NOVO JOGO"
========================================

PROBLEMA:
O botão "NOVO JOGO / SAIR" na tela de pausa não estava funcionando 
para sair do mapa e voltar à tela inicial.

RAIZ DO PROBLEMA:
O InputMap do painel de pausa estava usando WHEN_FOCUSED ao invés de 
WHEN_IN_FOCUSED_WINDOW, fazendo com que não recebesse eventos de teclado.

SOLUÇÃO IMPLEMENTADA:

Arquivo: src/telas/TelasJogo.java

1. Linha 480: InputMap
   ANTES: getInputMap(JComponent.WHEN_FOCUSED)
   DEPOIS: getInputMap(JComponent.WHEN_IN_FOCUSED_WINDOW)

2. Linhas 485-510: Validação isShowing()
   Adicionado: if (isShowing()) { ... }
   
3. Linhas 337-352: Callbacks seguros
   Adicionado: SwingUtilities.invokeLater()
   
4. Linhas 83-91: mostrarMenu()
   Adicionado: SwingUtilities.invokeLater()
   
5. Linhas 545-552: voltarParaMenu()
   Adicionado: SwingUtilities.invokeLater()

IMPACTO:
✓ Painel de pausa agora recebe eventos de teclado
✓ Navegação com CIMA/BAIXO/ENTER funciona
✓ Botão "NOVO JOGO" volta corretamente ao menu
✓ Código thread-safe com SwingUtilities
✓ Timing de UI otimizado

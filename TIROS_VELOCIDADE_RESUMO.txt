# ⚡ VELOCIDADE DOS TIROS - REDUZIDA ⚡

## ✅ ALTERAÇÃO CONCLUÍDA

A velocidade dos tiros foi **reduzida em 50%** para ambos os tanques (jogador e inimigo).

---

## 📊 RESUMO DA MUDANÇA

### Velocidade Anterior:
```
Tiro do Jogador:   4 pixels/frame → ~240 pixels/segundo
Tiro do Inimigo:   4 pixels/frame → ~240 pixels/segundo
```

### Velocidade Nova:
```
Tiro do Jogador:   2 pixels/frame → ~120 pixels/segundo  ⬇️ 50% mais lento
Tiro do Inimigo:   2 pixels/frame → ~120 pixels/segundo  ⬇️ 50% mais lento
```

---

## 🎮 EFEITO NO GAMEPLAY

### Antes (Rápido):
❌ Tiros muito velozes
❌ Difícil de esquivar
❌ Pouco tempo para reação

### Depois (Lento):
✅ Tiros mais controláveis
✅ Mais fácil de esquivar
✅ Mais tempo para reação
✅ Gameplay mais estratégico

---

## 📁 ARQUIVO MODIFICADO

**src/objeto/Tiro.java** - Linha 24

```diff
- this.velocidade = 4; // pixels por frame
+ this.velocidade = 2; // pixels por frame (reduzido de 4 para 2)
```

✅ **TanqueJogador.java**
   └─ Tiros criados usam velocidade padrão (2)

✅ **TanqueInimigo.java**

🚀 COMO USAR
═════════════════════════════════════════════════════════════════

OPÇÃO 1 - IntelliJ IDEA:
  1. Abra c:\Users\usuario\Desktop\BattleCity
  2. Clique direito em Main.java
  3. Selecione "Run 'Main.main()'"

OPÇÃO 2 - Terminal (CMD):
  cd c:\Users\usuario\Desktop\BattleCity
  javac -d bin src/jogo/*.java src/objeto/*.java src/mundo/*.java src/telas/*.java src/controles/*.java
  java -cp bin jogo.Main

OPÇÃO 3 - Usar .jar (se compilado):
  java -jar BattleCity.jar

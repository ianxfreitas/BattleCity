TESTE DO BOTÃO "NOVO JOGO" - INSTRUÇÕES COMPLETAS
=================================================

OBJETIVO:
Verificar se o botão "NOVO JOGO / SAIR" na tela de pausa volta
corretamente para a tela inicial do jogo (Menu Principal).

PASSO 1: COMPILAR O PROJETO
===========================
Execute um dos scripts:
  • compilar_rapido.bat (mais rápido)
  • compilar_novo_jogo_fix.bat (com detalhes)

Resultado esperado: ✓ Compilação com sucesso

PASSO 2: EXECUTAR O JOGO
========================
Na pasta bin, execute:
  java -cp bin jogo.Main

Resultado esperado: 
  ✓ Janela "Battle City DX" abre
  ✓ Tela inicial com "BATTLE CITY" e menu principal aparece

PASSO 3: INICIAR UMA PARTIDA
=============================
1. Selecione "1 PLAYER GAME"
2. Digite um nome e pressione ENTER
3. Escolha dificuldade (recomendado: VETERANO)
4. Pressione ENTER
5. Escolha tipo de tanque (qualquer um)
6. Pressione ENTER
7. Escolha mapa (recomendado: ALEATÓRIO)
8. Pressione ENTER

Resultado esperado:
  ✓ O mapa do jogo carrega
  ✓ Seu tanque aparece na base
  ✓ Inimigos aparecem nos cantos

PASSO 4: PAUSAR O JOGO
=======================
Pressione: ESC

Resultado esperado:
  ✓ Tela escurece/dimming
  ✓ Aparecem 3 opções:
    - >> CONTINUAR
    -    REINICIAR FASE
    -    NOVO JOGO / SAIR

PASSO 5: NAVEGAR ATÉ "NOVO JOGO / SAIR"
=========================================
1. Pressione CIMA para ir para opção anterior
2. Continue até chegar em "NOVO JOGO / SAIR"

Você saberá que está na opção correta quando:
  ✓ O texto piscar (>> NOVO JOGO / SAIR)

PASSO 6: EXECUTAR A AÇÃO
========================
Pressione: ENTER

Resultado esperado AGORA CORRIGIDO:
  ✓ Tela escurece/desaparece
  ✓ Volta para MENU PRINCIPAL
  ✓ Mostra "1 PLAYER GAME", "RANKING", "EXIT"
  ✓ Cursor está em "1 PLAYER GAME"
  ✓ Pode começar novo jogo

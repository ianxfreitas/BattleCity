## 📝 CÓDIGO PRINCIPAL ADICIONADO

### 2. Carregamento (no construtor)
```java
carregarImagem();
```

### 3. Método de Carregamento
```java
private void carregarImagem() {
    try {
        imagem = ImageIO.read(getClass().getResourceAsStream("/res/tanque.png"));
    } catch (IOException e) {
        System.err.println("⚠️  AVISO: Não foi possível carregar a imagem...");
        imagem = null;
    } catch (NullPointerException e) {
        System.err.println("⚠️  AVISO: Arquivo /res/tanque.png não encontrado...");
        imagem = null;
    }
}
```

### 4. Desenho (Novo)
```java
if (imagem != null) {
    Graphics2D g2d = (Graphics2D) g;
    // Aplicar rotação conforme direção
    AffineTransform transform = g2d.getTransform();
    g2d.rotate(rotacao, cx, cy);
    g2d.drawImage(imagem, x, y, largura, altura, null);
    g2d.setTransform(transform);
} else {
    // FALLBACK: Retângulo verde
    g.setColor(Color.GREEN);
    g.fillRect(x, y, largura, altura);
}
```

📊 VISÃO GERAL DOS 9 CONCEITOS POO
═══════════════════════════════════════════════════════════════════════════════

┌─ ENCAPSULAMENTO
│  └─ Esconde internals, expõe interface
│     Exemplo: shootCooldown private, atirar() public

┌─ ABSTRAÇÃO
│  └─ Simplifica complexidade
│     Exemplo: ObjetoJogo abstrata define contrato

┌─ HERANÇA
│  └─ Reutiliza código de classe base
│     Exemplo: TanqueJogador extends ObjetoJogo

┌─ POLIMORFISMO
│  └─ Mesmo método, comportamentos diferentes
│     Exemplo: atualizar() em cada classe diferente

┌─ THREADS
│  └─ Execução paralela independente
│     Exemplo: Cada tanque e tiro é uma Thread

┌─ INTERFACES
│  └─ Define contrato que classes implementam
│     Exemplo: Colidivel, Atirador, Movimentavel

┌─ ENUMS
│  └─ Constantes type-safe com valores relacionados
│     Exemplo: TipoTanque.AGIL, BALANCEADO, BLINDADO

┌─ COMPOSIÇÃO
│  └─ Combina objetos para criar estruturas complexas
│     Exemplo: PainelJogoV2 contém Mapa, Jogador, Inimigos

┌─ EXCEÇÕES
│  └─ Trata erros de forma robusta
│     Exemplo: try/catch em I/O e Threads

🔑 CONCEITOS-CHAVE PARA CADA CLASSE
═══════════════════════════════════════════════════════════════════════════════

ObjetoJogo
 ├─ ABSTRAÇÃO: classe abstrata define interface
 ├─ ENCAPSULAMENTO: atributos protected, métodos public
 └─ HERANÇA: base para TanqueJogador, TanqueInimigo, Tiro

TanqueJogador
 ├─ HERANÇA: extends ObjetoJogo
 ├─ THREADS: implements Runnable, método run()
 ├─ ENCAPSULAMENTO: movCima, shootCooldown private
 └─ ENUMS: TipoTanque, Direcao

TanqueInimigo
 ├─ HERANÇA: extends ObjetoJogo
 ├─ THREADS: implements Runnable com IA
 ├─ POLIMORFISMO: run() diferente de TanqueJogador
 └─ ENUMS: TipoInimigo, Direcao

Tiro
 ├─ HERANÇA: extends ObjetoJogo
 ├─ INTERFACES: implements Movimentavel, Runnable
 ├─ THREADS: cada tiro é uma Thread
 └─ ENUMS: Shooter (JOGADOR, INIMIGO)

PainelJogoV2
 ├─ COMPOSIÇÃO: contém Mapa, TanqueJogador, inimigos, tiros
 ├─ POLIMORFISMO: trabalha com ObjetoJogo genérico
 ├─ THREADS: cria/gerencia threads de tanques e tiros
 └─ EXCEÇÕES: trata interrupções de thread
